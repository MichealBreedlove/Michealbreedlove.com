Jasper Timeclock MFA

A personal safety-focused helper that retrieves a recent ExponentHR one-time verification code from Gmail after an MFA request.

What the app does

Jasper Timeclock MFA runs on the operator’s Windows computer as part of a private ExponentHR timeclock workflow. When ExponentHR requests multifactor authentication, the app searches for a recent message from exponenthr.com, reads the matching message, extracts the one-time code, and uses that code only to complete the requested authentication step.

The app is not a general email client and is not offered as a public service.

Google data access

The app requests only the Gmail read-only OAuth scope:

https://www.googleapis.com/auth/gmail.readonly

  • It does not send, modify, label, archive, or delete email.
  • It searches for recent ExponentHR MFA messages and reads only matching results needed for the authentication attempt.
  • It does not use Google data for advertising, profiling, or sale.
